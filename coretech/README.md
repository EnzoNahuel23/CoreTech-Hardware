# CoreTech - Tienda de Hardware

Tienda online desarrollada en React para la venta de componentes de hardware, consolas y periféricos.

## Tecnologías utilizadas

- React 19
- Vite
- React Router DOM
- React Bootstrap
- Bootstrap 5

## Instrucciones para instalar y correr el proyecto

```bash
cd coretech
npm install
npm run dev
```
