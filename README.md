# CoreTech Hardware - Tienda Online

## Descripción del Proyecto
Este proyecto es una aplicación web moderna que simula una tienda online especializada en componentes de hardware y computación de alto rendimiento. Desarrollada en el marco de la materia **Construcción de Interfaces de Usuario** de la **Universidad Nacional de Hurlingham (UNAHUR)**, la aplicación permite a los usuarios explorar un catálogo dinámico de productos, aplicar filtros avanzados por categorías, ver detalles técnicos específicos, gestionar un carrito de compras en tiempo real y completar un proceso de compra simulado mediante un formulario controlado.

## Tecnologías Utilizadas
* **React** (Vite) - Librería principal para la interfaz de usuario.
* **React Bootstrap** - Framework CSS para el diseño responsive y componentes de interfaz (Cards, Modals, Navbar).
* **React Router DOM** - Gestión de rutas dinámicas de la aplicación.
* **JavaScript (ES6+)** - Lógica de filtros, persistencia y estado global.

## Características Principales
* **Página de Inicio:** Banner con carrusel de novedades y acceso directo al catálogo.
* **Catálogo Dinámico:** Renderizado de productos desde un array de objetos con control de stock en tiempo real (bloqueo de botones sin stock).
* **Filtros Avanzados:** Buscador por nombre y filtrado por categorías de hardware.
* **Vista de Detalle:** Rutas dinámicas para visualizar características técnicas específicas de cada componente.
* **Carrito de Compras:** Gestión de cantidades, cálculo de subtotales, total general y persistencia de datos.
* **Formulario Controlado:** Validación de datos de contacto y confirmación de compra interactiva mediante un modal.
